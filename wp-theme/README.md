# قالب وردپرس ArshamDecor

قالب شرکتی/معماری فارسی (RTL) که از یک طراحی استاتیک HTML تبدیل شده است.

## ساختار

- `header.php` / `footer.php` : هدر و فوتر مستقل قابل استفاده در همه صفحات
- `front-page.php` : صفحه اصلی (۱۱ سکشن)
- `template-parts/home/*` : پاره‌قالب‌های هر سکشن صفحه اصلی
- `template-parts/cards/project-card.php` : کارت پروژه (داخلی/نما)
- `inc/*` : راه‌اندازی، enqueue، CPTها، Customizer، Walker منو، متاباکس پروژه
- `assets/` : Css، Js، Img، Fonts

## نصب

1. پوشه‌ی این قالب را zip کنید (به‌طوری که `style.css` در ریشه‌ی zip باشد).
2. پیشخوان → نمایش → پوسته‌ها → افزودن → بارگذاری پوسته → zip را انتخاب کنید.
3. فعال‌سازی.
4. تنظیمات → پیوندهای یکتا → روی «نام نوشته» ذخیره کنید.

## تنظیمات پس از فعال‌سازی

- **نمایش → فهرست‌ها** : سه منو بسازید:
  - `Primary (Mega Menu)`
  - `Footer - Demos column`
  - `Footer - Quick links column`
- **نمایش → سفارشی‌سازی → ArshamDecor - Contact & Social** : تلفن، موبایل، ایمیل، آدرس، متن CTA، متن Intro، لینک شبکه‌های اجتماعی.
- **تنظیمات → خواندن** : یک صفحه‌ی ثابت به‌عنوان صفحه اصلی انتخاب کنید (یا خالی بگذارید تا `front-page.php` مستقیم لود شود).

## محتوای نمونه (اختیاری)

- **اسلایدها (Slides)** : ۲ آیتم با تصویر شاخص
- **مزایا (Benefits)** : ۶ آیتم با تصویر شاخص (آیکون SVG)
- **خدمات (Services)** : ۳ آیتم با تصویر شاخص
- **پروژه‌ها (Projects)** : با تعیین نوع پروژه:
  - `interior` برای «دکوراسیون داخلی» (فیلدهای: مدت، شهر، متراژ)
  - `facade` برای «نمای ساختمانی» (فیلد: نوع سنگ)

## نکات فنی

- Bootstrap 4.1.1 داخل `assets/Css/Main.css` گنجانده شده است.
- `@font-face`ها در `assets/Css/Style.css` مسیر `../Fonts/` را می‌گیرند، پس ساختار پوشه‌ها را تغییر ندهید.
- `assets/Js/init.js` اسلایدرهای Owl را راه‌اندازی می‌کند (در نسخه‌ی استاتیک اصلی مقداردهی نشده بودند).
- `.my_sticky` و `.explain-menu` و `.m_search` توسط `Custom.js` کنترل می‌شوند و کلاس‌هایشان توسط وردپرس (`wp_nav_menu`) و مارک‌آپ `header.php` تأمین می‌شود.
